# HOME Market Supermarket 🛒🇷🇼

> **Rwanda's Premier Multi-Category Marketplace & Online Supermarket**
> Delivering fresh groceries, electronics, fashion, home essentials, and Made in Rwanda crafts across all 30 districts of Rwanda.

---

## 🌟 Key Features

- **🛍️ 47+ Structured Categories**: From groceries, pharmacy, fresh produce from Musanze, electronics, to traditional Rwandan crafts.
- **🚚 30-District Rwandan Logistics Engine**: Dynamic delivery fee calculations & estimated delivery times for Kigali (Gasabo, Nyarugenge, Kicukiro) and all nationwide provinces.
- **💳 Multi-Payment Integration Simulation**: Support for MTN Mobile Money (*182#), Airtel Money, and Visa/Mastercard escrow checkout.
- **🏬 4D Interactive Supermarket & Storefronts**: Modern immersive shopping showcase.
- **👥 Multi-Role Ecosystem**:
  - **Customer Portal**: Real-time order progress timeline (Placed ➔ Confirmed ➔ Processing ➔ Out for Delivery ➔ Delivered).
  - **Vendor Dashboard & Onboarding**: Store customization, live sales tracking, and order fulfillment.
  - **Admin Operations Center**: Real-time category CRUD and marketplace management.
  - **Investor Hub & Strategy**: Rwandan e-commerce vision and market opportunity.
- **🌐 Multilingual Support**: English, Kinyarwanda, and French.

---

## 🚀 Tech Stack

- **Frontend**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla Modern CSS Design System (Custom variables, glassmorphism, responsive grid)
- **Icons & Effects**: [Lucide React](https://lucide.dev/), [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **State Management**: React Context API with persistent `localStorage` synchronization

## 🛠️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/primo8/Home-market.git
cd Home-market

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Production Build

```bash
npm run build
npm run preview
```
